# Trip Guangzhou (27 Nov – 2 Dis 2026)

Offline-capable PWA: daily itinerary with Guangzhou weather (Open-Meteo), CNY ➜ MYR converter (ExchangeRate-API, Frankfurter fallback) and flight lists. Last weather and rate are kept in localStorage for offline use.

Bump `VERSION` in `sw.js` whenever you change `index.html`.
