# Trip Guangzhou (27 Nov – 2 Dis 2026)

Offline-capable PWA: daily itinerary with Guangzhou weather (Open-Meteo), CNY ➜ MYR converter (ExchangeRate-API, Frankfurter fallback) flight lists, and a Malay ⇄ Chinese translator (DeepSeek; API key is entered in the app and kept in the phone's localStorage only, never in this repo). Last weather and rate are kept in localStorage for offline use.

Bump `VERSION` in `sw.js` whenever you change `index.html`.
